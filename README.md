#  Projets de Programmation Java Summer 2026

Bienvenue dans le repository regroupant les projets de programmation Java réalisés par les étudiants de la classe.

## 🎯 Objectif

Ce repository a pour objectif de centraliser les travaux des cinq groupes de la classe.

Chaque groupe dispose d'un espace dédié pour déposer :

- son exposé ;
- son code Java ;
- sa documentation ;
- ses différents fichiers de projet.

---

# 👥 Les cinq groupes

## Groupe 1: Système de gestion de bibliothèque universitaire

Le projet consiste à développer un programme permettant de gérer une bibliothèque universitaire.

### Principales fonctionnalités

- Gestion des documents
- Gestion des adhérents
- Gestion des emprunts et retours
- Calcul des pénalités
- Recherche de documents
- Réservation d'ouvrages
- Consultation de l'historique
- Génération de rapports

---

## Groupe 2:  Suivi de patients et rendez-vous médicaux

Le projet consiste à créer une application permettant de gérer les patients, les médecins et les rendez-vous d'un cabinet médical.

### Principales fonctionnalités

- Gestion des patients
- Gestion des médecins
- Gestion des rendez-vous
- Modification et annulation des rendez-vous
- Planning des médecins
- Comptes rendus
- Historique des patients
- Statistiques

---

## Groupe 3: Plateforme de quiz en ligne avec mode temps réel

Le projet consiste à développer une application permettant à un enseignant de créer des quiz et aux étudiants d'y répondre.

### Principales fonctionnalités

- Création de quiz
- Questions à choix multiples
- Questions vrai/faux
- Questions à réponse courte
- Gestion des réponses
- Calcul des scores
- Classement
- Exportation des résultats

---

## Groupe 4: Simulation de transactions bancaires sécurisées

Le projet consiste à simuler un système bancaire permettant de gérer les comptes et les transactions.

### Principales fonctionnalités

- Création de comptes
- Authentification
- Consultation du solde
- Dépôts
- Retraits
- Virements
- Historique des transactions
- Détection simple de fraude
- Gestion administrative
- Export des relevés

---

## Groupe 5: Gestion intelligente de stocks avec alertes et prévisions

Le projet consiste à développer un système permettant de gérer les stocks d'une petite entreprise.

### Principales fonctionnalités

- Gestion des produits
- Gestion des catégories
- Gestion des fournisseurs
- Entrées et sorties de stock
- Historique des mouvements
- Alertes de stock
- Calcul de la consommation moyenne
- Suggestion de réapprovisionnement
- Tableau de bord
- Génération de rapports

---
